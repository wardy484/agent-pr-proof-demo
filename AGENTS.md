# Agent Instructions

This repository is a public demonstration of a small, evidence-backed PR.

## Working rules

- Implement only the selected GitHub issue.
- Keep the change small and avoid unrelated refactoring.
- Do not add a database or JavaScript unless the issue requires it.
- Add focused feature tests for behaviour.
- Run `php artisan test` and `vendor/bin/pint --test`.
- Capture a screenshot when visible behaviour changes.

## Pull-request proof

The PR description must state:

1. what changed;
2. why it changed;
3. how it was tested;
4. what visual evidence is attached.
